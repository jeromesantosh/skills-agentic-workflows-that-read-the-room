## Mona's editorial angle

- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates

- **Nov 4, 2026: GitHub Copilot in Xcode.** Copilot is now available in Xcode's built-in coding assistant in public preview. ([GitHub Changelog](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant))
- **Nov 4, 2026: CodeQL 2.27.4.** This release includes query accuracy improvements for GitHub's code scanning engine. ([GitHub Changelog](https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata))
- **Nov 3, 2026: Dependabot supports Agent Package Manager (APM).** Add an `apm` entry to `.github/dependabot.yml` to get version-update PRs for git dependencies in `apm.yml`; security updates are not covered. ([GitHub Changelog](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager))
- **Nov 3, 2026: GitHub Copilot in JetBrains Air.** Delegate coding tasks to Copilot locally or in the cloud using your existing Copilot subscription. ([GitHub Changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air))
- **Dec 2, 2026: `pull_request_target` blocked by default in public repos.** Unless an Actions event policy allows it; private and internal repos are unaffected. Brownouts start Nov 9, so review your workflows now. ([GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2))
